# Default O&M Outline (use only when no prior JMS O&M template is available)

This outline follows common wastewater-equipment O&M practice and typical 01 78 23 / 01 33 00 requirements. It is **not** a JMS-issued template. Replace it with the team's standard once one is identified, and check the project spec for required sections.

0. Cover page: project name and number, owner/plant, contractor, EoR, spec section, equipment, JMS contact, revision block, Prepared By (PE initials), date
1. Open Items (draft only; remove before submittal)
2. Table of contents
3. Safety
   - lockout/tagout
   - confined space
   - rotating equipment
   - pinch points at gates
   - hazardous-area notes
   - lifting points
4. Equipment description and data
   - scope summary
   - equipment list with tags, P/Ns, quantities
   - design data from the approved submittal: capacity, material basis, rpm, HP, gate size and rating, materials
5. Receiving, storage and handling
   - long-term storage: gear reducer oil fill per mounting position, motor heaters, rotating shafts periodically
   - lifting provisions
6. Installation
   - anchorage (reference the anchor calc and hardware)
   - alignment and leveling
   - assembly notes, e.g.:
     - flange bolts with anti-seize
     - gate seal bolts 50 in-lb in a cross pattern with anti-seize
     - roller guide bolts 280 in-lb with anti-seize
   - electrical connections
7. Startup and commissioning
   - pre-start checklist
   - rotation check
   - no-load run
   - load run
   - performance test method (as agreed in the submittal)
8. Operation
   - normal operation
   - startup/shutdown sequences (e.g., silo loadout: start chute → rotary valve → vibrator after ~1 min; stop vibrator first, rotary valve last)
   - operating limits
   - gates open/close only; discharge rate by screw speed
   - fill limits where applicable
9. Maintenance
   - preventive maintenance table (task / interval / lubricant or part / qty / reference)
   - lubrication chart
   - inspection points: liner wear, flight wear, seals, gate seals and rollers
10. Troubleshooting (symptom / cause / remedy)
11. Spare parts (recommended and spec-required, with P/Ns and vendor)
12. Warranty and contacts (JMS aftermarket/field service; vendor contacts)
Appendices (bookmarked):
- A. Approved submittal drawings
- B. Vendor O&M manuals by component
- C. Motor and gearbox data (English cutsheets, nameplates)
- D. Control panel documentation (if in JMS scope)
- E. Test reports
- F/G… Closeout forms (Equipment Maintenance Summary, Maintenance Requirements), one per item as required
